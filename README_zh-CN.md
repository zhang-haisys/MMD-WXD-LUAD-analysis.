## 使用

在R环境中将工作目录设为解压后的仓库根目录。先运行：

```r
source("scripts/check_environment.R", encoding = "UTF-8")
```

它只检查安装情况和语法，不执行分析。把config/config.example.R复制为
config/config.local.R，填写本机路径；输入文件放到workspace/0.data。
补齐原始辅助函数、核实处理细节并解决对应模块问题后，才启用配置中的运行开关。
从仓库根目录在终端逐个运行，例如：

```text
Rscript scripts/run_module.R 02
```

不能直接从第一份到最后一份一键运行：现有资料缺少辅助函数及部分中间步骤。
14号外部验证文件仍含示例基因及系数，不能作为本研究外部验证结果的依据。
07号实际是相关性分析，不应因原文件名就宣称完成单基因GSEA。
